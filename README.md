# lesson-check

> Pre-lesson diagnostics for online-school students: a Windows tool that finds and safely fixes camera, microphone, sound and network problems (run remotely via RustDesk), plus a browser check page for any device.

Самая частая заявка в поддержке онлайн-школы — «на уроке не работает камера / не слышно / всё зависает». Раньше специалист проверял это вручную по удалённому доступу, пункт за пунктом. **lesson-check** делает эту диагностику за минуту и чинит то, что можно починить безопасно.

---

## Два инструмента

### 1. Программа для компьютера ученика (Windows 10/11)

Специалист запускает её через RustDesk. Около 40 секунд программа только проверяет и ничего не меняет, потом по каждой проблеме спрашивает «Исправить? [Д/Н]».

**Проверяет:**
- **камеру** — видит ли её Windows, нет ли ошибки драйвера, не запрещён ли доступ, какая программа её занимает (Zoom, Teams…), не блокирует ли антивирус, не запрещена ли камера для сайта урока в Chrome, Edge, Яндекс Браузере, Opera
- **микрофон и звук** — включены ли, громкость, «не тот» микрофон по умолчанию, Bluetooth-гарнитура в режиме разговора, тест записи с автоматическим определением голоса
- **интернет** — пинг, DNS, скорость, сигнал Wi-Fi, прокси и VPN, сбитые часы (из-за них не открываются https-сайты)
- **компьютер** — устройства без драйверов, ожидающая перезагрузка, нехватка памяти и программы, которые грузят процессор, место на диске, кэш браузеров

**Исправляет только после согласия:** разрешения Windows, громкость, службы звука и камеры, перезапуск устройств, время (только если два независимых сервера согласны), прокси, кэш DNS, запрет камеры для сайта в браузере, кэш браузеров.

**Безопасность ремонта:**
- никогда не трогает пароли, cookies, историю, закладки, файлы ученика, сетевые драйверы
- каждое обратимое изменение пишется в журнал, `-Undo` возвращает всё как было
- глубокий ремонт драйверов (`-Deep`) — только после точки восстановления Windows
- честно говорит, что починить нельзя: сломанная камера, шторка, запрет политикой, сеть провайдера

**Отчёт** сохраняется на рабочий стол и копируется в буфер обмена — специалист вставляет его в комментарий заявки. Последняя строка отчёта — коды проблем: по ним [бот поддержки](https://github.com/luciuverus/support-relay) и [дашборд](https://github.com/luciuverus/support-sla-dashboard) считают, какие проблемы встречаются чаще всего.

### 2. Страница проверки в браузере (любое устройство)

Для учеников с Mac, телефоном или планшетом. За минуту проверяет браузер (не открыта ли ссылка внутри Telegram или WhatsApp), камеру (картинка, «тёмный» кадр, мало кадров в секунду), микрофон, звук, скорость интернета и **проходит ли через сеть ученика видеосвязь (UDP)** — частая причина «камера работает, а на уроке чёрный экран».

По каждой проблеме — пошаговая подсказка под устройство: Windows, macOS, iPhone, Android. Видео и звук никуда не отправляются.

## Техническая сторона

| | |
|---|---|
| Программа | PowerShell, около 2 400 строк, запуск через `lesson-check.bat` |
| Страница | один HTML-файл без зависимостей (WebRTC, getUserMedia, Web Audio), около 640 строк |
| Режимы | `-CheckOnly` — только проверка, `-Deep` — ремонт драйверов, `-Undo` — откат |
| Отчёт | текстовый файл + машиночитаемая строка `#lesson-check … problems=… left=…` |

## Структура

```
student-pc/   lesson-check.bat, lesson-check.ps1 — программа для ПК ученика
web/          index.html, ping.txt — страница проверки
docs/         GUIDE_RU.txt — полная инструкция для специалистов поддержки
```

Для своего замера скорости положите рядом со страницей файл `speed-5mb.bin` (любые 5 МБ). Без него страница меряет скорость через Cloudflare.
